# 多模态 RAG 项目前端字段字典

> 文档用途：给前端工程师做页面建模、TypeScript 类型定义、表单设计、列表渲染、错误提示与状态管理时使用。
>
> 当前状态更新：文档中的配置类接口字段已由后端实现，前端可直接依据本文档定义类型。

---

## 1. 字段类型约定

### 1.1 基础类型映射

| 文档类型 | TypeScript 推荐类型 | 说明 |
|---|---|---|
| number | `number` | 数值型 |
| string | `string` | 字符串 |
| boolean | `boolean` | 布尔值 |
| object | `Record<string, any>` 或明确 interface | 对象 |
| array | `T[]` | 数组 |
| null | `null` | 空值 |
| string \| null | `string \| null` | 可空字符串 |
| number \| null | `number \| null` | 可空数字 |

### 1.2 时间字段约定

当前接口中的时间字段采用 ISO 8601 字符串。

## 8. 配置更新统一响应

```ts
export interface ConfigUpdateResponse {
  message: string;
  applied: boolean;
  need_restart: boolean;
  current?: Record<string, any> | null;
}
```

当前后端返回策略：

- `applied = true`
- `need_restart = false`

含义：

- 配置已成功写入数据库
- 新请求默认按数据库配置优先执行
- 一般不需要因为这批配置变更而手动重启后端

## 10. 给前端工程师的特别提醒

1. 配置类接口现在已经实现，可直接联调。
2. 问答响应现在包含 `rerank_status`。
3. 若系统设置页修改了模型、embedding、reranker、top_k/top_n，新请求会直接使用新配置。
4. 查询配置接口中密钥已脱敏；若不想改密钥，更新时请传空字符串。
