# 多模态 RAG 项目前后端接口文档

> 文档用途：用于后端向前端工程师移交时的接口对接说明。
>
> 当前状态更新：**文档管理、问答、系统设置配置接口均已实现**，可直接联调。
>
> 说明：本文档中会区分：
>
> 1. **当前已实现接口**：可以直接调用。
> 2. **后续可扩展能力**：不是当前必须联调项。

## 1. 服务基础信息

### 1.1 服务地址

- 本地开发默认地址：`http://localhost:8010`
- Swagger 文档：`http://localhost:8010/docs`
- OpenAPI JSON：`http://localhost:8010/openapi.json`

### 1.2 接口前缀

所有业务接口统一挂载在：

- `http://localhost:8010/api`

例如：

- 健康检查：`GET /api/health`
- 文档上传：`POST /api/rag/ingest`

### 1.3 跨域

当前后端已开启全量 CORS：

- `allow_origins = ["*"]`
- `allow_methods = ["*"]`
- `allow_headers = ["*"]`

因此前端本地联调时通常不需要额外处理跨域。

### 1.4 统一返回说明

当前项目的返回格式**未做统一包装**，即：

- 查询类接口：直接返回对象或数组
- 上传类接口：直接返回业务结果对象
- 出错时：FastAPI 默认返回

```json
{
  "detail": "错误说明"
}
```

建议前端统一兼容以下两种情况：

#### 成功响应

```json
{
  "field": "value"
}
```

#### 失败响应

```json
{
  "detail": "错误说明"
}
```

## 3.2 获取文档列表

### 接口状态

- **已实现**

### 请求信息

- 方法：`GET`
- 路径：`/api/rag/documents`

### 请求参数

无。

### 成功响应示例

```json
[
  {
    "id": 12,
    "file_name": "科研指令合集_06 Sep.pdf",
    "status": "ready",
    "created_at": "2026-04-22T10:15:23.123456"
  }
]
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | number | 文档主键 ID |
| `file_name` | string | 原始文件名 |
| `status` | string | 文档状态，当前常见为 `ready` / `processing` |
| `created_at` | string | ISO 时间字符串 |

## 3.3 批量上传并入库文档

### 接口状态

- **已实现**

### 请求信息

- 方法：`POST`
- 路径：`/api/rag/ingest`
- Content-Type：`multipart/form-data`

### 表单参数

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `files` | file[] | 是 | 多文件上传字段，可重复传多个 |
| `overwrite` | boolean | 否 | 是否覆盖库中已存在的同内容文件，默认 `false` |

### 成功响应示例

```json
{
  "total": 2,
  "succeeded": 2,
  "failed": 0,
  "items": [
    {
      "file_name": "A.pdf",
      "success": true,
      "document_id": 21,
      "parent_chunks": 8,
      "child_chunks": 26,
      "images": 3,
      "already_exists": false,
      "overwritten": false,
      "error": null
    }
  ]
}
```

## 3.6 对话问答接口

### 接口状态

- **已实现**

### 功能说明

支持：

1. 非流式返回完整答案
2. 流式 SSE 返回
3. 返回 `rerank_status`，便于前端感知 reranker 是否启用、是否降级

### 请求信息

- 方法：`POST`
- 路径：`/api/rag/ask`
- Content-Type：`application/json`

### 请求体示例

```json
{
  "question": "请总结研究生培养方案的主要要求",
  "stream": false
}
```

### 非流式响应示例

```json
{
  "answer": "一、总：...",
  "citations": [],
  "rerank_status": {
    "enabled": true,
    "used": true,
    "fallback": false,
    "mode": "rerank",
    "provider": "dashscope-rerank",
    "model": "gte-rerank-v2",
    "reason": "success",
    "requested_top_n": 8,
    "returned_count": 8
  }
}
```

### 流式说明

当 `stream=true` 时，返回 `text/event-stream`。

当前 SSE 消息类型：

- `token`
- `citations`
- `done`

## 3.7 系统设置：模型配置接口

### 3.7.1 获取模型配置

- 方法：`GET`
- 路径：`/api/rag/config/model`
- 状态：**已实现**

响应示例：

```json
{
  "llm": {
    "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "******",
    "model_name": "qwen-plus",
    "timeout": 120
  },
  "embedding": {
    "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "******",
    "model_name": "text-embedding-v3"
  },
  "vision": {
    "enabled": false,
    "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "******",
    "model_name": "qwen-vl-max-latest"
  },
  "source": "db"
}
```

### 3.7.2 更新模型配置

- 方法：`PUT`
- 路径：`/api/rag/config/model`
- 状态：**已实现**

请求体示例：

```json
{
  "llm": {
    "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "sk-xxx",
    "model_name": "qwen-plus",
    "timeout": 120
  },
  "embedding": {
    "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "sk-xxx",
    "model_name": "text-embedding-v3"
  },
  "vision": {
    "enabled": true,
    "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "sk-xxx",
    "model_name": "qwen-vl-max-latest"
  },
  "apply_mode": "persist_and_reload"
}
```

响应示例：

```json
{
  "message": "模型配置已更新",
  "applied": true,
  "need_restart": false
}
```

### 当前行为说明

- 配置会写入数据库中的 `default` 配置记录
- 新问答请求会优先读取数据库配置
- 若不传新的 `api_key`，则保留旧值

## 3.9 系统设置：检索参数接口

### 3.9.1 获取检索参数

- 方法：`GET`
- 路径：`/api/rag/config/retrieval`
- 状态：**已实现**

响应示例：

```json
{
  "top_k": 15,
  "keyword_top_k": 15,
  "final_top_n": 8,
  "description": {
    "top_k": "向量召回条数",
    "keyword_top_k": "关键词召回条数",
    "final_top_n": "Reranker 之后最终保留条数"
  }
}
```

### 3.9.2 更新检索参数

- 方法：`PUT`
- 路径：`/api/rag/config/retrieval`
- 状态：**已实现**

请求体示例：

```json
{
  "top_k": 20,
  "keyword_top_k": 10,
  "final_top_n": 6,
  "apply_mode": "persist_and_reload"
}
```

响应示例：

```json
{
  "message": "检索参数已更新",
  "applied": true,
  "need_restart": false,
  "current": {
    "top_k": 20,
    "keyword_top_k": 10,
    "final_top_n": 6
  }
}
```

### 当前行为说明

- 更新后，新问答请求会按新参数生效
- `final_top_n` 必须小于等于 `top_k + keyword_top_k`

## 4. 当前运行时配置说明

当前项目已改为：

- 默认从 `.env` / `app/core/config.py` 读取基础配置
- 若数据库中存在 `default` 配置，则**优先使用数据库配置**

当前已热生效的配置包括：

- 文本大模型配置
- Embedding 配置
- 视觉模型开关与模型配置
- Reranker 开关、模型、超时、Key
- 检索参数 `top_k / keyword_top_k / final_top_n`

影响范围包括：

- 问答调用
- 向量检索
- rerank 逻辑
- 图片描述生成
- 新建向量库实例时使用的 embedding 配置

## 6. 常见错误码与前端处理建议

| HTTP 状态码 | 场景 | 建议处理 |
|---|---|---|
| `200` | 成功 | 正常处理 |
| `400` | 参数错误 / 文件格式不支持 / 检索参数非法 | 直接提示用户 |
| `404` | 文档不存在 | 刷新列表并提示 |
| `422` | 请求体验证失败 | 提示表单参数错误 |
| `500` | 服务内部错误 | 提示“系统异常，请稍后重试” |

## 8. 给前端工程师的特别提醒

1. 当前系统设置页可直接联调，不再是预留接口。
2. 上传接口字段名是 **`files`**。
3. 流式问答使用 SSE，不是 WebSocket。
4. 配置更新后，新请求默认按数据库配置优先执行。
5. 查询配置接口返回的密钥字段为脱敏值 `******`，更新时若不想改密钥，可以传空字符串。
